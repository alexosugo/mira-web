# Sellogram wordmark master

The production wordmark is the **Disciplined** Gate 1 refinement, selected on 2026-09-03.

Authoritative vector:

`brand/identity/wordmark/master/sellogram.svg`

The master uses outlined vector paths and `currentColor`, so the same geometry is used for dark, reversed, and monochrome applications.

Do not recreate the wordmark with a font. Do not substitute the source PNG or any Gate 1 review raster for this master.

The Gate 1 candidate files remain as design history. `disciplined` is the selected geometry; `faithful` and `characterful` are not active logo variants.
