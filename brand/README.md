# Sellogram Brand

Sellogram is the only active public brand. Mira is retired.

The canonical name is **Sellogram**: uppercase `S`, lowercase `ellogram`.
Sellogram is one cohesive word. Never abbreviate it as `SG`, split it into initials, or create an `SG` monogram.

## Identity masters

- Primary wordmark: `identity/wordmark/master/sellogram.svg`
- Compact identity: `identity/symbol/master/sellogram-symbol.svg`

The compact identity is **S / Pure**: the capital `S` from the official wordmark. Use it only where the full wordmark cannot fit, such as favicons, app icons, avatars, and small UI surfaces.
